This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```


## File Organization
`app/` - Contains the routes/pages of the application
`components/` - Contains reusable UI components
`components/ui` - Contains UI components that are used across the application(eg. Button, Input, Checkbox) individual components.
`components/common` - Contains common components that are used across the application(eg. Header, Footer, Sidebar) full components.
`lib/` - Contains utility functions and libraries used across the application.
